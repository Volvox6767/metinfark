# ⚖️ MetinFark — Text Diff

**🇬🇧 English | [🇹🇷 Türkçe aşağıda](#-t%C3%BCrk%C3%A7e)**

Compare two texts **line by line** and instantly see additions and removals — right in your browser. **No upload, no account, no internet needed.**

- ⚖️ Side-by-side diff with color-coded `+ added` / `− removed` lines
- 🧠 LCS-based alignment (handles insertions, deletions, rewrites)
- ⚡ Fast on large texts (common prefix/suffix trimming)
- 📊 Live stats: how many lines added, removed, common
- 🔄 One-click swap & clear, `Ctrl+Enter` shortcut
- 📴 100% offline — works from a single HTML file, nothing leaves your device

## 🚀 How to use
1. Open `index.html` in any browser (double-click it — no install).
2. Paste the **original** text on the left, the **changed** text on the right.
3. Click **⚖️ Karşılaştır / Compare** (or press `Ctrl+Enter`).
4. Green lines = added, red lines = removed. Stats show the totals.

**Use cases:** comparing essay drafts, config files, code snippets, translations, price lists — anything textual.

## 🇹🇷 Türkçe

İki metni **satır satır** karşılaştır, eklenen ve silinen satırları anında gör — tamamen tarayıcında. **Yükleme yok, hesap yok, internet gerekmez.**

- ⚖️ Yan yana diff, renkli `+ eklenen` / `− silinen` satırlar
- 🧠 LCS tabanlı hizalama (ekleme, silme, yeniden yazma durumları)
- ⚡ Uzun metinlerde hızlı (ortak baş/son kırpma)
- 📊 Canlı istatistik: kaç satır eklendi, silindi, ortak
- 🔄 Tek tıkla değiştir & temizle, `Ctrl+Enter` kısayolu
- 📴 %100 offline — tek HTML dosyasından çalışır, hiçbir veri cihazından çıkmaz

## 🚀 Nasıl kullanılır
1. `index.html` dosyasını herhangi bir tarayıcıda aç (çift tıkla — kurulum yok).
2. Soldaki alana **orijinal** metni, sağdaki alana **değişmiş** metni yapıştır.
3. **⚖️ Karşılaştır** düğmesine bas (veya `Ctrl+Enter`).
4. Yeşil satırlar = eklenen, kırmızı satırlar = silinen. İstatistik toplamları gösterir.

**Nerede işinize yarar:** ödev taslakları, ayar dosyaları, kod parçaları, çeviriler, fiyat listeleri karşılaştırma — metin olan her şey.
